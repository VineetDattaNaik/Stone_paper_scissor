# Stone-Paper-Scissor Game

A simple and interactive Stone-Paper-Scissor game built with HTML, CSS, and JavaScript.

## Features

- Play Stone-Paper-Scissor against the computer
- Real-time score tracking
- Visual feedback for game results
- Responsive design

## How to Play

1. Open `index.html` in your web browser
2. Click on one of the three options: Stone (Rock), Paper, or Scissors
3. The computer will randomly select its move
4. The winner is determined by the classic rules:
   - Stone beats Scissors
   - Paper beats Stone
   - Scissors beats Paper
5. The score updates automatically after each round

## Files

- `index.html` - Main game structure
- `style.css` - Game styling
- `game.js` - Game logic
- Image files: rock.png, paper.png, scissors.png

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
